Manual ranges are feature-domain values, not audio gain. AUTO restores the frozen learned range; LOCKED snapshots the current active range. For pitch motion, the learned/active range is a magnitude range (for example 12.3 … 184.0 cents), while live raw motion remains signed. Reloading the page does not alter the device.
